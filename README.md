Branch Structure: The Branches are structures with a main branch and 3 different feature branches along with a dev branch for player messages and a hotfix branch for any fixes necessary. 







Branch Descriptions: Main branch is the initial game while feature one is the quit feature and feature two implements a maximum attempt logic along with a game over condition being included. Feature 3 is a hint feature, the dev branch adds in encouraging messages to players, and the hotfix branch properly includes a max value in range for the game.
