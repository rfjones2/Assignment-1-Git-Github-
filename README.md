Branch Structure: At the projects start the branches are structures in an order of last completed with the main branch being at the bottom and the hotfix branch being at the top.



Branch Descriptions: Each individual branch brings in it's own new feature such as a quit feature, a game over feature, a player feedback feature, and the main game feature along with out created document branch.



Learning Summary: Merge will merge different branches together and makes a commit of them while rebase adds another most recent commit onto the new branch. Squash combines all previous commits into the new commit, and cherry-pick picks a commit and adds it into the branch. Feature1 was lacking the majority of features found in feature3 and feature2 was only lacking a couple features, but feature3 has a commit history that was difficult to read through since the final commit was labeled done. In real projects I would use merge to combine two ideas, rebase to add an idea to my current one, squash to remove an overabundance of commits, and cherry-pick to add on an idea I found.
